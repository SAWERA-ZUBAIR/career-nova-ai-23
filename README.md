# Career Nova AI

An AI-powered career platform that helps students, fresh graduates, and job seekers discover jobs, internships, scholarships, and remote opportunities while providing personalized AI career guidance.

# Problem Statement

Finding authentic jobs, internships, scholarships, and remote opportunities requires searching multiple websites, making the process time-consuming and confusing.

Career Nova AI solves this problem by bringing all career opportunities into one platform with intelligent AI tools that help users make better career decisions.

# How to Run the Project

Clone the repository

```bash
git clone https://github.com/SAWERA-ZUBAIR/career-nova-ai-23.git
```

Go to the project folder

```bash
cd career-nova-ai-23
```

Install dependencies

```bash
npm install
```

Run the project

```bash
npm run dev
```
